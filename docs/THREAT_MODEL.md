# 威胁模型初稿

| 威胁 | 影响 | 防护和验证 |
| --- | --- | --- |
| 越租户读取 | 泄露项目和成果物 | tenant scope、RBAC、RLS 测试 |
| Agent 伪造人工审批 | 未审核结果进入论文 | actor kind 分离、Review 门禁 |
| 路径越权 | 读取队员电脑任意文件 | 工作区白名单、沙箱、路径测试 |
| 数据外发 | 题目或答案泄露 | 默认禁网、外发策略、审计 |
| 重放请求 | 重复领取或重复批准 | 幂等键、请求哈希、唯一约束 |
| 竞态覆盖 | 新结果被旧结果覆盖 | 租约、版本不可变、事务锁 |
| 未来数据泄漏 | 结果不可实施 | 信息边界声明和运行时读取审计 |
| 恶意文件 | 执行或存储风险 | MIME/大小校验、隔离执行、病毒扫描扩展 |
