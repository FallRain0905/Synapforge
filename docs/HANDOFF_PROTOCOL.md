# 交接协议

交接包必须能够让接收方不读取发送方聊天记录就开始工作。最小字段包括目标、完成项、输入/输出成果物、结论、假设、证据、未决问题、风险和下一步。

## 类型

- `RELAY`：一个上游任务交给一个下游任务或 Agent。
- `FANOUT`：一个任务拆分给多个并行执行者。
- `AGGREGATE`：汇总多个已批准前置任务的结果。

## 状态

```text
CREATED -> ACCEPTED
       \-> REJECTED -> NEEDS_REVISION
       \-> BLOCKED
```

接收确认必须记录接收主体、时间和幂等键。交接输出和输入引用必须属于同一项目；未接受或未通过门禁的交接不能推动下游。
