# 权限矩阵初稿

| 操作 | Project Lead | Contributor | Reviewer | Observer | Agent |
| --- | --- | --- | --- | --- | --- |
| 查看项目 | 是 | 是 | 是 | 是 | 按项目授权 |
| 创建任务 | 是 | 是 | 否 | 否 | 由任务协议授权 |
| 领取/执行任务 | 是 | 是 | 可选 | 否 | 按能力和租约 |
| 创建成果物 | 是 | 是 | 是 | 否 | 按任务授权 |
| 提交 Review 建议 | 是 | 是 | 是 | 否 | 可提交非批准意见 |
| 人工批准 | 是 | 否 | 是 | 否 | 否 |
| 修改已批准版本 | 否 | 否 | 否 | 否 | 否，必须新版本 |
| 导出正式交付包 | 是 | 否 | 可选 | 否 | 否 |

Agent 的权限是项目和能力范围的交集，不能因为拥有者是 Project Lead 就继承成员全部权限。
