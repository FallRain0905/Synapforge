## 1. 聊天区 `/task`：直接建任务，不用切 Tab

- 输入框里敲 `/task 任务标题` 回车即建任务：命令识别在**统一提交入口**（`submitCompose`）里，
  命令优先于普通发言，不会把 `/task …` 当聊天内容发出去。
- 建完后自动发一条消息：`已新建任务「…」（在「任务」Tab 里派单与设置执行方式）`，
  并且这条消息带**任务引用**（气泡里出现「查看任务」）。
- 输入框上方会显示预览条 `[/task] 回车将新建任务：<标题>`，让这个能力可见；
  占位提示也补了 `/task 建任务`。
- `/` 唤起的选择器里，**命令排在最前**（`/task` 提示语"直接新建任务：/task 任务标题"），
  后面才是 Agent 列表——一条通道同时承载"叫 Agent"和"下命令"。
- 后端配套：`ProjectMessageCreate.ref_task_id` + `post_project_message(ref_task_id=)`，
  校验**任务属于本项目**（跨项目引用返回 `message_task_not_in_project`），两个契约测试。

## 2. 成果物右侧抽屉：就地看内容，不跳页

新增 `components/artifact-drawer.tsx`，在聊天流与成果空间都能一键展开：

- **触发点**：人类"已上传…"消息、Agent 成果卡片（含系统行的"成果物"小链接）、成果空间的「查看」按钮；
  名字从卡片文案里取（`「指南终稿.md」` 这种），不再显示成笼统的"成果物"。
- **抽屉内容**：正文（文本类成果物直接读 `/content`）+ **来源与状态**（产出任务、执行运行、门禁、
  版本血缘、复核、被哪些任务引用）+ 下载 + 「在成果物库打开」深链；Esc 或点遮罩关闭。
- **类型判定以服务端详情为准**：聊天卡片里通常只有 id，客户端先取 `/detail` 再决定是否读正文；
  二进制/结构化类型不硬解，直接提示下载。
- 演示项目现在**真的能读到文档**：种子脚本给四份产出写了正文（提纲 258B、初稿 730B、复核意见 350B、
  终稿 967B 的 markdown），所以点开就是一份能看的《平台使用指南》。

## 3. `/ask` 按参考图改版

参考图的形态是"左列会话 + 右列对话（顶部工具条 + 底部整宽输入）"，照此重排：

- **左列（264px）**：顶部整宽描边按钮「+ 新对话」；会话**按日期分组**（今天 / 昨天 / 更早），
  每行标题 + `日期 · 模式 · 条数`，当前会话左侧高亮条，悬停出现删除（触屏常显）。
- **右侧对话区**：顶部工具条 = 会话标题 + **知识库下拉** + 「检索会话」+「管理文档 →」（指向 `/kb`）；
  中间消息区（用户浅灰气泡右对齐、回答左对齐、来源 chips）；底部整宽输入 + 发送，输入区钉底。
- 未选会话直接输入仍会自动新建；两栏等高、页面不滚动（沿用 W-6 的内容区滚动骨架），
  窄屏（≤980px）会话列折到上方、限高内滚。

## 4. 顺手修掉的真 bug：中文文件名的下载 500

做抽屉时暴露的（**此前所有中文名成果物的下载都是 500**）：

`download_artifact_content` 等三处把文件名直接塞进 `Content-Disposition: attachment; filename="指南终稿.md"`，
而 Starlette 把响应头按 **latin-1** 编码 → `UnicodeEncodeError` → 500。修法：统一走 `content_disposition()`
助手，按 RFC 5987 输出 `filename="artifact.md"; filename*=UTF-8''<percent-encoded>`（纯中文名再给一个
`artifact.<ext>` 的 ASCII 兜底）。**实测**：线上 `GET /api/artifacts/{id}/content` → 200，
头里 `filename*=%E6%8C%87%E5%8D%97...`，正文正常返回。

另外演示数据有个边界：成果物**批准后不可再写内容**（`approved_artifact_is_immutable`），
所以给老演示补正文的做法是**重建演示项目**（`scripts/deploy/_demo_reseed.py` 按外键顺序清理 +
重新种），本地与线上都已重建。

## 6. 边界

- `/task` 只建"标题级"任务（阶段固定为 modeling、中优先级、未指派）；要更细的字段（阶段/优先级/截止/
  执行方式/输入成果物）仍走「任务」Tab 的新建或"设置执行方式"。
- 抽屉里**只读**：不能编辑内容、不能在抽屉里批准门禁（批准仍在 `/review`）。
- 抽屉对**二进制/结构化产出**只给元信息 + 下载，不做渲染（figure/compiled_pdf 这类要看图得下载）。
- `/ask` 的知识库下拉只影响"新建检索会话"绑定哪个库；**切换已有会话的知识库**接口不支持，
  所以没做成可改的下拉（避免界面承诺做不到的事）。
- 会话仍无重命名、回答仍非流式（既有边界延续）。
