## 1. 做了什么

整套配色换成**黑白灰**，去掉三样"AI 味"最重的东西：**蓝紫渐变**、**大块彩色底**、**彩色气泡/徽章**。

- **强调色 = 近黑**：主按钮从"蓝→紫渐变"变成实心 `#171717`（深色主题下是近白 `#EDEDED`）；
  链接、选中项、当前页高亮、批次徽章全部跟它走。
- **侧栏**：#101823（藏青）→ `#111111`（纯黑灰）；选中项从"蓝色渐变 + 蓝色左条"变成
  "半透明白底 + 白色左条"。
- **状态表达换成"中性底 + 一个语义色圆点"**：以前是整块绿/黄/红/紫底，现在底色统一为
  `--surface-muted`，只有 6px 的小圆点带颜色。信息还在，但屏幕不再花。
- **聊天流**：人类消息 = 浅灰气泡（`--accent-soft`），Agent/系统 = 白底卡片 + 左侧细色条；
  Agent 徽章从紫色改成实心近黑。
- **图表**：吞吐柱从蓝紫渐变改成灰阶（深灰=成功、浅灰=失败），深色主题反转。
- **主题色 meta**（`layout.tsx`）与文档页里两处内联琥珀色一并同步。

**保留了三处语义色**（已降饱和）：`--green #3f6b52`、`--amber #7a5c1e`、`--red #a13c34`
（深色主题下分别是 `#7fae94` / `#c9a86a` / `#d99a92`），只用在状态点、少量关键数字和
危险按钮上——否则"哪个任务卡住了、哪个门禁没过"在一屏灰里看不出来。

## 4. 想更"纯灰"怎么做

现在是"灰 + 三个降饱和语义色"。如果连红/黄/绿都不要（全灰）：

```css
/* apps/web/app/globals.css 末尾追加即可 */
:root { --green: #525252; --green-soft: #f0f0f0; --amber: #525252; --amber-soft: #f0f0f0; --red: #171717; --red-soft: #f0f0f0; }
:root[data-theme="dark"] { --green: #a3a3a3; --green-soft: #262626; --amber: #a3a3a3; --amber-soft: #262626; --red: #ededed; --red-soft: #262626; }
```

代价：门禁"未通过/通过"、任务"受阻"、风险数字会失去颜色区分，只能靠文案和小圆点的深浅辨别。

## 5. 边界

- **没有做布局/排版改动**：字号、间距、圆角、组件结构全部保持原样，这次只换颜色。
- **超图可视化 `/graph` 仍用自己的节点配色**（G6 图谱的调色板在 `app/graph/page.tsx` 里，
  灰阶化会让节点类别无法区分）。它现在在「高级工具」分组里，日常看不到；
  要一起灰化请说一声。
- **`/kb`「向量库浏览」的图表、AI 问答里的富文本**沿用各自组件的颜色（多为继承色，已随令牌变灰）。
- 深色主题的语义色是"亮版"（如 `--green #7fae94`），在近黑底上才看得清；这是刻意的。
