# 领域术语表

## 核心对象

| 术语 | 定义 | 事实来源 |
| --- | --- | --- |
| Organization | 租户边界，拥有队伍和项目 | 平台数据库 |
| Team | 组织内参与同一协作空间的成员集合 | 平台数据库 |
| Project | 一次竞赛或知识生产项目 | 平台数据库 |
| Task | 有明确输入、输出和完成标准的可执行工作单元 | 平台状态机 |
| Handoff | 不依赖聊天上下文的结构化交接包 | 平台成果物关系 |
| Artifact | 可版本化、可哈希、可审核的文件或结果 | 平台成果物索引 |
| Run | 一次代码、模型或审计执行及其 Manifest | 平台运行记录 |
| Evidence | 支撑结论的成果物、运行、事件或外部来源 | 平台证据关系 |
| Review | 对任务、成果物或交接的审查意见 | 平台审核记录 |
| Gate | 允许或阻断下游工作的规则和状态快照 | 平台门禁记录 |
| Event | 对项目事实变化的不可变审计事件 | 平台事件日志 |
| Agent | 代表模型或本地执行环境工作的自动化主体 | Agent 注册表 |
| Human Member | 具有成员身份并可执行人工审批的主体 | 身份服务 |

## 状态词

- `DRAFT`：尚未进入可执行队列。
- `READY`：依赖满足，可以被领取。
- `CLAIMED`：已经被 Agent 租约占用。
- `RUNNING`：正在执行。
- `WAITING_REVIEW`：执行完成，等待审核。
- `APPROVED`：已经通过正式门禁，可作为下游正式输入。
- `NEEDS_REVISION`：需要修订后重新执行或提交。
- `BLOCKED`：被规则、依赖或风险阻断。
- `FAILED`：执行失败，可按规则重试。
- `CANCELLED`：主动取消且不可继续执行。

## 正式与非正式信息

聊天、草稿和临时运行只能提供上下文，不得单独推动工作流。只有 Task、Handoff、Artifact、Run、Review、Gate 和 Event 的持久化记录可以作为正式事实。
